# Comparatoo
Dans le cadre de la refonte des services du Middleware Orange travaille avec ATOS (ESN) dans le but de faire une montée de version du JDK7 vers le JDK21. Des tests doivent être réaliser sur les services développé en JDK21. Le programme s'organise en plusieurs fichiers permettant l'export, la modification et la comparaison de ces webservices.
